# NFC Card Emulation в OctoDiary

## Обзор

Реализована возможность клонирования и эмуляции NFC-карт доступа (например, школьных пропусков) для прохода через турникеты.

## Возможности

- ✅ Сканирование NFC-карт (чтение UID и технических данных)
- ✅ Сохранение данных карты локально
- ✅ Эмуляция карты через HCE (Host Card Emulation)
- ✅ Работа в фоновом режиме
- ✅ Поддержка различных типов карт (NFC-A, Mifare Classic, ISO-DEP)

## Архитектура

### 1. Компоненты

#### `nfc/CardEmulationService.kt`
- **HCE сервис** для эмуляции карты
- Обрабатывает APDU-команды от считывателя
- Возвращает сохранённый UID карты
- Работает в фоновом режиме

#### `nfc/NfcCardManager.kt`
- **Менеджер NFC-карт**
- Проверка доступности NFC
- Чтение карт (UID, тип, технологии)
- Сохранение/загрузка/удаление данных карты
- Управление Reader Mode

#### `components/settings/NfcCard.kt`
- **UI-компонент** для управления картами
- Сканирование карты
- Отображение сохранённых данных
- Удаление карты

### 2. Данные

#### Сохранённые данные (`CachePrefs`)
- `nfc_card_uid`: UID карты (hex)
- `nfc_card_type`: тип карты (NFC-A, Mifare, ISO-DEP)
- `nfc_card_tech`: список поддерживаемых технологий
- `nfc_card_data`: дополнительные данные (ATQA, SAK, Historical Bytes)
- `nfc_card_saved_at`: timestamp сохранения

### 3. Манифест

#### Разрешения
```xml
<uses-permission android:name="android.permission.NFC" />
<uses-feature android:name="android.hardware.nfc" android:required="false" />
<uses-feature android:name="android.hardware.nfc.hce" android:required="false" />
```

#### HCE сервис
```xml
<service
    android:name=".nfc.CardEmulationService"
    android:exported="true"
    android:permission="android.permission.BIND_NFC_SERVICE">
    <intent-filter>
        <action android:name="android.nfc.cardemulation.action.HOST_APDU_SERVICE" />
    </intent-filter>
    <meta-data
        android:name="android.nfc.cardemulation.host_apdu_service"
        android:resource="@xml/apduservice" />
</service>
```

#### AID конфигурация (`res/xml/apduservice.xml`)
```xml
<host-apdu-service
    android:description="@string/nfc_service_desc"
    android:requireDeviceUnlock="false">
    <aid-group android:description="@string/nfc_aid_group_desc" android:category="other">
        <aid-filter android:name="F0010203040506" />
    </aid-group>
</host-apdu-service>
```

## Как использовать

### 1. Клонирование карты

1. Откройте `Настройки → Security → NFC Card Emulation`
2. Нажмите **"Scan card"**
3. Приложите карту доступа к задней части телефона
4. Дождитесь успешного сканирования
5. Данные карты будут сохранены

### 2. Использование эмулированной карты

1. После сканирования эмуляция работает автоматически
2. Просто приложите телефон к турникету/считывателю
3. Телефон будет эмулировать сохранённую карту
4. Работает даже при заблокированном экране

### 3. Удаление карты

1. Откройте `Настройки → Security → NFC Card Emulation`
2. Нажмите **"Clear saved card"**
3. Данные карты будут удалены

## Поддерживаемые типы карт

### NFC-A (ISO 14443-A)
- Базовый протокол NFC
- Читается: UID, ATQA, SAK
- Используется в большинстве пропусков

### Mifare Classic
- Популярный тип карт доступа
- Типы: Classic, Plus, Pro
- Читается: UID, тип карты

### ISO-DEP (ISO 14443-4)
- Расширенный протокол
- Читается: UID, Historical Bytes
- Используется в банковских картах и современных пропусках

## Технические детали

### APDU-команды

#### SELECT команда
```
Header: 00 A4 04 00
Response: [UID] 90 00
```

#### Статусы ответа
- `90 00`: SUCCESS
- `6F 00`: UNKNOWN/ERROR

### Формат UID
- Hex-строка (например, `04A1B2C3D4E5F6`)
- Длина: 4, 7 или 10 байт
- Уникальный идентификатор карты

## Ограничения

### Технические
- ❌ Не поддерживается чтение защищённых секторов Mifare
- ❌ Не поддерживается эмуляция карт с криптографией
- ❌ Работает только на устройствах с NFC HCE
- ⚠️ Некоторые турникеты могут не принимать эмулированные карты

### Безопасность
- ⚠️ UID хранится в незашифрованном виде в SharedPreferences
- ⚠️ Нет аутентификации при эмуляции
- ⚠️ Клонирование чужих карт может быть незаконным

### Совместимость
- ✅ Android 4.4+ (API 19+) для чтения
- ✅ Android 4.4+ (API 19+) для HCE
- ✅ Требуется NFC-чип с поддержкой HCE

## Безопасность и легальность

### Рекомендации
1. **Клонируйте только свои карты**
2. **Не передавайте данные карт третьим лицам**
3. **Используйте PIN-код для защиты приложения**
4. **Удаляйте данные карты при продаже/передаче телефона**

### Правовые аспекты
- Клонирование собственной карты доступа обычно легально
- Клонирование чужих карт может быть незаконным
- Проверьте правила вашей школы/организации
- Администрация может заблокировать карту при обнаружении клонирования

## Устранение неполадок

### NFC не работает
- Проверьте, включён ли NFC в настройках телефона
- Убедитесь, что телефон поддерживает NFC HCE
- Перезагрузите телефон

### Карта не сканируется
- Убедитесь, что карта поддерживает NFC
- Попробуйте разные положения карты относительно телефона
- Снимите чехол с телефона
- Проверьте, не разряжена ли батарея

### Турникет не открывается
- Убедитесь, что карта сохранена
- Попробуйте приложить телефон ближе к считывателю
- Проверьте, не заблокирована ли оригинальная карта
- Некоторые турникеты не поддерживают HCE-эмуляцию

### Эмуляция не работает
- Проверьте, что сервис `CardEmulationService` запущен
- Убедитесь, что приложение установлено как платёжное по умолчанию (в некоторых случаях)
- Проверьте логи: `adb logcat | grep CardEmulation`

Отредактируйте `CardEmulationService.processCommandApdu()`:
```kotlin
override fun processCommandApdu(commandApdu: ByteArray?, extras: Bundle?): ByteArray {
    // Ваша логика обработки
}
```

```bash
adb logcat | grep -E "CardEmulation|NfcCardManager"
```
