# План разработки OctoDiary

## 1. Подготовка среды (Эмулятор)
**Статус:** Выполнено
**Задача:**
- Найти `emulator.exe` (предположительно в `G:/AndroidStudio` или SDK).
- Получить список AVD (Android Virtual Devices).
- Запустить эмулятор в отдельном окне, перенаправив вывод логов в файл, чтобы не блокировать терминал.

*Итог:*
Найден `emulator.exe` в `G:\AndroidStudio\emulator\`. Найдены AVD: `Pixel_6_Pro`, `Pixel_6_Pro_x86-64`. Запущен `Pixel_6_Pro_x86-64` в фоновом режиме через `Start-Process`. Логи пишутся в `emulator_out.log`.

## 2. Починить NFC
**Статус:** Выполнено
**Задача:**
- Исправить вылет приложения при поднесении к турникету.
- Исправить ошибку на турникете.
- Найти реализацию `HostApduService` и проверить логику обработки APDU команд.

*Итог:*
Найден `CardEmulationService.kt`. Обнаружена уязвимость в `hexToByteArray`, которая вызывала краш при неверном формате сохраненного UID. Метод переписан с использованием `try-catch` и безопасной обработки ошибок. Теперь сервис возвращает пустой ответ или ошибку, но не роняет приложение.

## 3. Создать OctoRunner (ADB Framework)
**Статус:** Выполнено
**Задача:**
- Написать инструментарий (набор скриптов или класс на Python/Kotlin) для управления эмулятором через ADB.
- Функции: тапы, свайпы, ввод текста, снятие скриншотов, получение иерархии UI.
- Это позволит "видеть" приложение и тестировать его.

*Итог:*
Создан `tools/octorunner.py`. Это Python-скрипт, обертывающий команды ADB. Реализованы методы `tap`, `swipe`, `input_text`, `press_key`, `take_screenshot`, `dump_ui`. Скрипт успешно протестирован созданием скриншота эмулятора.
