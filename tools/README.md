# OctoDiary Tools

Набор утилит для автоматизации тестирования, отладки и взаимодействия с Android-приложением через ADB (Android Debug Bridge).

## Скрипты

### `octorunner.py`
Основной скрипт-обертка над ADB для выполнения частых задач.

**Возможности:**
- Снятие скриншотов (`screenshot`).
- Дамп иерархии UI в XML (`dump`).
- Эмуляция нажатий (`tap`) и свайпов (`swipe`).
- Ввод текста и нажатие аппаратных кнопок.

**Примеры использования:**

```bash
# Сделать скриншот и сохранить как screenshot.png
python octorunner.py screenshot

# Сохранить структуру UI в ui_dump.xml
python octorunner.py dump

# Эмуляция тапа по координатам (x, y)
python octorunner.py tap 500 1000
```

### `octotester.py`
*(Если применимо)* Скрипт для запуска тестов или сценариев проверки (предположительно использует `octorunner.py` для выполнения шагов).

## Требования
- Python 3
- `adb` в системном PATH
- Подключенное Android-устройство или эмулятор с включенной отладкой по USB.
