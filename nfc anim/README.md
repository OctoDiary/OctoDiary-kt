# NFC Animation Prototypes

В этой директории находятся прототипы UI-компонентов, связанных с NFC-функционалом приложения.

## Описание

Проект представляет собой React-компоненты (предположительно для использования в веб-вью или как референс для реализации на Compose), демонстрирующие анимацию оплаты/прохода через турникет.

## Содержимое

- **`App.tsx`**: Точка входа, демонстрация переключения тем (светлая/темная).
- **`components/NFCPaymentAnimation.tsx`**: Основной компонент анимации взаимодействия по NFC.
- **`components/ui/`**: Набор базовых UI-компонентов (shadcn/ui style), используемых в анимации.
- **`styles/`**: Глобальные стили (Tailwind CSS).

## Использование

Этот код служит визуальным образцом (design reference) для реализации анимаций в основном Android-приложении или может быть использован в веб-версии сервиса.
