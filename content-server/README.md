# OctoDiary Content Server

МСР (Model Context Protocol) сервер для предоставления образовательного контента. Этот модуль реализует серверную часть (или локальный сервис), который позволяет AI-агентам или клиенту запрашивать информацию из учебников и параграфов.

## Назначение

Сервер предоставляет инструменты (Tools) для протокола MCP, позволяя:
- Получать оглавление учебников (`get_table_of_contents`).
- Запрашивать текст параграфов (`request_paragraph`).
- Искать контент по ключевым словам (`search_content`).
- Получать список доступных учебников (`list_textbooks`).

Может использоваться как бэкенд-сервис или компонент для расширения возможностей AI-ассистента внутри приложения.

## Установка и запуск

Требуется Node.js.

1.  Установка зависимостей:
    ```bash
    npm install
    ```

2.  Сборка проекта (TypeScript -> JavaScript):
    ```bash
    npm run build
    # Или для Windows
    npm run build:win
    ```

3.  Запуск сервера:
    ```bash
    npm start
    ```

## Структура

- **`src/index.ts`**: Основной файл сервера. Содержит определение инструментов MCP и mock-данные (в текущей реализации).
- **`package.json`**: Зависимости и скрипты.
