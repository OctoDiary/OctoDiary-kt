# OctoDiary Content MCP Server

MCP-сервер для доступа к образовательному контенту OctoDiary, включая оглавления учебников и параграфы по требованию.

## Возможности

### Инструменты (Tools)

1. **get_table_of_contents** - Получение оглавления учебника
   - Параметры: `textbookId` (обязательный), `level` (опциональный)

2. **request_paragraph** - Запрос параграфа по теме
   - Параметры: `topic` (обязательный), `language` (опциональный, по умолчанию "ru"), `maxLength` (опциональный)

3. **search_content** - Поиск по контенту
   - Параметры: `query` (обязательный), `textbookId` (опциональный), `limit` (опциональный, по умолчанию 10)

4. **list_textbooks** - Получение списка доступных учебников
   - Параметры: нет

## Установка

```bash
cd content-server
npm install
npm run build:win
```

## Настройка

Добавьте сервер в конфигурацию MCP settings (c:\Users\Анастасия\AppData\Roaming\Code\User\globalStorage\rooveterinaryinc.roo-cline\settings\mcp_settings.json):

```json
{
  "mcpServers": {
    "octodiary-content": {
      "command": "node",
      "args": ["G:\\OctoDiary\\content-server\\build\\index.js"],
      "disabled": false,
      "alwaysAllow": [],
      "disabledTools": []
    }
  }
}
```

## Использование

После настройки сервер будет автоматически доступен через MCP протокол. Доступные инструменты можно использовать для:

- Навигации по оглавлениям учебников
- Получения образовательного контента по темам
- Поиска по существующему контенту
- Управления учебными материалами

## Примечание

В текущей реализации используется моковые данные для демонстрации. Для полноценной работы необходимо интегрировать подключение к реальной базе данных OctoDiary через соответствующие DAO и репозитории.
